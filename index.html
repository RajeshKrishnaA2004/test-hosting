What is DNS?

DNS stands for Domain Name System. Think of it as the internet's phonebook.

🌐

Domain Name

A human-friendly website name, such as example.com.

🔎

DNS Lookup

The process of finding the DNS information associated with a domain name.

🖥️

IP Address

An address that helps your device locate a server across a network.

How DNS works

A simplified journey from a website name to its server.

You enter a domain
↓
DNS resolver checks its cache
↓
DNS records are looked up if needed
↓
Your browser connects to the server
↓
The website loads

Common DNS records

Different records provide different kinds of DNS information.

Record Purpose Example
A Maps a name to an IPv4 address 192.0.2.1
AAAA Maps a name to an IPv6 address 2001:db8::1
CNAME Points one name to another name www → example.com
MX Identifies mail servers mail.example.com
TXT Stores text used for verification and configuration Domain verification
